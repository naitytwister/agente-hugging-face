# Agente Hugging Face & Model Scout 🚀

Workspace do agente especialista em exploração, pesquisa e varredura ativa no ecossistema Hugging Face.

## 🎯 Objetivos
- **Descoberta Inteligente (`hf-research`):** Tradução de demandas de IA/ML em consultas de alta precisão no Hub, avaliando modelos, datasets e Spaces com dados em tempo real.
- **Otimização Contínua de Pipelines (`hf-model-scout`):** Varredura ativa contra a baseline de pipelines (`pipelines-registro.md`) para reduzir custos, latência e complexidade de código sem aumento de infraestrutura.
- **Governança de Licenças e Hardware:** Verificação prévia de viabilidade de execução local (CPU/RAM leve) e conformidade comercial (MIT, Apache 2.0).

## 📁 Estrutura de Arquivos
- `01_persona.txt`: Definição de papel, identidade e tom do agente.
- `02_contexto.txt`: Ferramentas MCP (`huggingface`), restrições operacionais e hardware.
- `03_tarefa.txt`: Loop de Orquestração (Perceber, Pensar, Agir, Checar).
- `04_formato.txt`: Especificação visual e técnica dos relatórios.
- `pipelines-registro.md`: Inventário baseline dos agentes monitorados.
- `AGENTS.md`: Diretrizes de governança e integração com subagentes.

## 📂 Skills (em `skills/`)
- `hf-research/SKILL.md`: Pesquisa avançada no Hugging Face Hub.
- `hf-model-scout/SKILL.md`: Varredura diária de modelos para otimização de pipelines.
